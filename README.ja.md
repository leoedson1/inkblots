# Inkblots

Inkblotsは、[Ink](https://www.inklestudios.com/ink/)のインタラクティブフィクション用スクリプトを扱うビジュアルデスクトップエディターです。ノットとステッチをカード、ダイバートを接続線、選択肢を構造化された行として表示しながら、通常の`.ink`テキストを信頼できる唯一の情報源として維持します。

> Inkblotsは独立したプロジェクトであり、Inkleとは提携していません。

[最新のWindows版をダウンロード](https://github.com/leoedson1/inkblots/releases/latest)

## はじめに

最初にはっきり言っておきます。このプロジェクトは、シナリオ執筆を助けるこんなツールがすぐに欲しかったという理由で、**ほぼ完全にノリと勢いでバイブコーディングしたものです**。そして私は**JavaScriptのことをマジで何も知りません**。現時点のInkblotsは私自身の目的には十分使えますが、もっと多くの人が楽しんで使えるようになるまで機能を磨き続けたいので、**皆さんからのフィードバックを心から歓迎します**。

#### あまり歓迎しないフィードバック

- ロゴがダサい（分かっています。数分で作ったので、そのうち改善するかもしれません）。
- どこかのノードで「+」アイコンがずれている（もう見つけています。気になって仕方ありません）。
- 面白くしようとしているのが気に入らない（そう思う人は多いです。賢い人ならもうやめていたでしょう）。

それはさておき、今のInkblotsは、まだInkを学んでいる私のような人には十分役立つので、あなたにも役立つかもしれません。私自身がこの言語に慣れるにつれて、スクリプト言語のロジックとノードの連携を、整合性を保ちながらより直感的に使えるよう改善していくつもりです。そのため、皆さんの利用体験をぜひ聞かせてください。それが改善を早めてくれるはずです。

## 主な機能

- ドラッグ可能な接続線を備えた無限キャンバス上で、ノットとステッチを配置。
- ノード上で物語本文や選択肢を直接編集するか、Ink構文を強調表示するインスペクターを使用。
- ネストした選択肢、ギャザー、分岐応答、条件、変数への作用を文脈に沿って表示。
- 自動調整されるゾーン、付箋、検索、ミニマップで大きな物語を整理。
- インスペクターからグローバル変数、定数、リストを管理。
- `inkjs`で物語をコンパイルして再生し、選択したノットから初期状態でテスト。
- 複数の`.ink`ファイルをタブで開き、最近使ったファイルをディスクから再度開く。
- 英語、日本語、簡体字中国語、ブラジルポルトガル語に対応。（日本語や中国語の翻訳がおかしければ、ぜひ修正点を教えてください。ブラジルポルトガル語については、**私を信じてください。分かっています**。）

## Inkとの互換性

Inkblotsは通常の`.ink`ファイルを読み書きします。キャンバス上の位置や整理情報は削除可能なInkコメントとして保存されるため、物語はInky、inklecate、Unity連携、その他のInkランタイムとの互換性を保ちます。

```ink
// --- Inkblots layout (safe to delete) ---
// @layout {"forest":[410,80],"cottage":[740,260]}
```

Inkblotsのメタデータを削除しても、ビジュアルレイアウトがリセットされるだけで、物語の内容は削除されません。

## インストール

[最新リリース](https://github.com/leoedson1/inkblots/releases/latest)からWindowsインストーラーをダウンロードしてください。

macOSとLinux向けのパッケージ設定もありますが、現在このリポジトリで公開しているのは動作確認済みのWindowsビルドのみです。

## ソースから実行

Inkblotsには最新のNode.jsが必要です。

```powershell
cd ink-node-editor
npm install
npm start
```

各プラットフォーム向けのインストーラーを作成するには、次を実行します。

```powershell
npm run dist
```

## 開発

Electronアプリケーションは[`ink-node-editor`](ink-node-editor)にあります。主なチェックコマンドは次のとおりです。

```powershell
cd ink-node-editor
npm test
npm run test:design
npm run test:choices
npm run test:canvas
npm run test:languages
```

詳しくは、[エディターとアーキテクチャの詳細資料](ink-node-editor/README.md)および[リリース履歴](CHANGELOG.md)をご覧ください。

## プロジェクトの状況

Inkblotsは現在も活発に開発されています。特に新しいリリースを試す際は、重要な物語をバックアップし、元の`.ink`ファイルをバージョン管理してください。
